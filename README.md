# BlockEarth

The real world at 1:1 scale, rebuilt in blocks — in the browser.

Type any address and the neighbourhood is generated live from OpenStreetMap: terrain, roads with lane
markings, parks, water, trees, street lamps, and every building at its real footprint and height, with
windows, pitched roofs and furnished interiors. Walk, fly, break and place blocks, and watch the windows
light up at night.

Built with **Three.js** and plain JavaScript (about 1,900 lines). No game engine, no backend.

> Not affiliated with Mojang or Microsoft. All textures are generated by code in `src/atlas.js`.

## Run it

```bash
npm install
npm run dev        # http://localhost:5173
```

Open the page, search for a place (or click a city), and click the world to grab the mouse.
The green "offline demo" buttons use map extracts shipped in `public/demo/`, so they work even when the
public map servers are busy: Midtown Manhattan (18,000 buildings with real heights), central New Delhi
(a 2016 snapshot), HSR Layout in Bengaluru, central Helsinki and Utrecht's old town. Every other place on
Earth is fetched live when you search for it.

| Key | Action |
| --- | --- |
| W A S D | move |
| Space / Q | jump, or up / down while flying |
| Shift | sprint / fly fast |
| F (or double-tap Space) | toggle fly / walk |
| Click / Right-click | break / place a block |
| 1–9, mouse wheel | choose a block |
| T | cycle time of day |
| M | toggle the minimap |
| Esc | menu (search, render distance, time) |

Deep links work: `/#48.85837,2.29448` opens straight at that coordinate.
URL options: `?r=10` render distance in chunks, `?t=21` hour of day, `?data=demo/new-york.json` use a bundled extract.

Dense skylines are heavy: Midtown at a large render distance is many millions of triangles, so lower the
render distance in the menu if it stutters.

## Host it

```bash
npm run build      # static files in dist/
```

Upload `dist/` to any static host — Netlify, Vercel, Cloudflare Pages, GitHub Pages, S3, or your own
server. The build uses relative paths, so it also works from a sub-folder. It must be served over
`http(s)://` (not opened as a file), because it uses ES modules and Web Workers.

### Before you send real traffic to it

The app talks directly to three free public services:

| Service | Used for | Notes |
| --- | --- | --- |
| Overpass API | map shapes | shared, rate limited — the app allows 2 requests at a time, retries on mirrors, and caches tiles in IndexedDB |
| Nominatim | address search | max ~1 request/second; no heavy use |
| Terrarium tiles (AWS Open Data) | terrain height | public bucket |

That is fine for a demo and a YouTube audience trickling in. For serious traffic, point `OVERPASS` and
`NOMINATIM` in `src/config.js` at your own instances (or a paid geocoder such as Mapbox), or pre-bake
popular cities into JSON extracts like the ones in `public/demo/` and add them to `DEMOS`.

You must keep the attribution **"© OpenStreetMap contributors"** visible (it is in the HUD and menu).

## How it works

```
OpenStreetMap ──► features ──► voxels ──► mesh ──► world
   osm.js          osm.js     generate.js  mesher.js  world.js
```

| File | Job |
| --- | --- |
| `src/config.js` | constants, data-source URLs, preset places |
| `src/geo.js` | lat/lon ⇄ local metres, deterministic hash |
| `src/elevation.js` | decodes terrain PNG tiles into heights |
| `src/osm.js` | Overpass query, download, tags → buildings / roads / areas |
| `src/blocks.js` | the block table (textures + flags) |
| `src/atlas.js` | paints every texture procedurally |
| `src/generate.js` | rasterises features into a chunk of blocks (terrain, roads, buildings, interiors, trees) |
| `src/mesher.js` | visible-face meshing with baked ambient occlusion |
| `src/worker.js` | Web Worker: generate + mesh off the main thread |
| `src/world.js` | tile downloads, chunk streaming, level of detail, block edits |
| `src/player.js` | mouse look, walk / fly physics, block ray cast |
| `src/sky.js` | day/night cycle, sun, moon, stars, clouds |
| `src/ui.js` | menu, search, HUD, hotbar, minimap |
| `src/main.js` | renderer, shader, game loop |
| `src/cache.js` | IndexedDB cache for downloaded tiles |

Scale is true: one block is one metre, positions come from a local projection around the place you
searched for, and heights come from the `height` / `building:levels` tags when mappers have added them.

## Honest limits

- **Interiors are invented.** No public dataset contains the inside of buildings; rooms and furniture
  are generated from a hash of the building ID (so they are the same on every visit).
- **Heights are only as good as the map.** Where a building has no height tag, it is estimated from
  its type. Coverage varies a lot between cities.
- **Bridges and tunnels are flat**: bridges are drawn at ground level, tunnels are skipped.
- **Desktop only** for now (keyboard + mouse, WebGL 2).
- **Single player.** Edits live in memory and are lost on reload.
- The world is centred on the place you searched; walking tens of kilometres away slowly loses
  precision — search again to re-centre.
